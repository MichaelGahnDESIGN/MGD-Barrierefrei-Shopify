# Einrichten

Installiere die Theme-App-Erweiterung über einen Shopify-CLI-App-Release. Aktiviere anschließend den App-Embed im Theme-Editor. Lege eine Seite „Barrierefreiheit“ an, ergänze den Block **MGD Erklärung Barrierefreiheit** und verknüpfe diese Seite im App-Embed. Alle Angaben liegen in den Theme-Einstellungen und können später ohne Code geändert werden.
