# Sicherheitsrichtlinie

Sicherheitslücken bitte vertraulich über die Sicherheitsfunktion des Repositories melden. Keine Shop-URL mit Zugang, API-Schlüssel, Kundendaten oder Screenshots mit Bestelldaten in Issues oder Pull Requests veröffentlichen.

Die Theme-App-Erweiterung nutzt keine serverseitige Speicherung. Die Bedienhilfe speichert ausschließlich Darstellungswünsche im Browser. `SHOPIFY_API_KEY` bleibt eine lokale Umgebungsvariable und wird nie eingecheckt.
